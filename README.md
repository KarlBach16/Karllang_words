# KarlLang

KarlLang is a typing-first German vocabulary trainer for adult learners.

## Key Features

- Typing-based learning for better memory retention
- Multiple study modes: Card, Copy, Typing, and Cram
- Spaced repetition (SRS) review logic built on local storage
- 100% offline: no internet connection required after installation
- Privacy focused: no login, no ads, no data collection

## Platform

- iOS app (built with HTML/CSS/JavaScript + Capacitor)
- All user data is stored locally on the device
