# KarlLang PRD - 2026-05-22

## 0. 문서 목적

이 문서는 2026-05-22 기준 KarlLang 앱의 현재 제품 정의, 주요 기능, 데이터 정책, 코드 구조를 정리한다.

기존 `docs/prd_260109.txt`는 초기 개발 스냅샷으로 보존한다. 현재 개발 기준 문서는 이 파일을 우선한다.

## 1. 제품 정의

KarlLang은 typing-first vocabulary trainer다.

핵심 목표는 단어를 눈으로 알아보는 recognition보다, 직접 입력해서 떠올리는 active recall을 강화하는 것이다.

### 1.1 제품 원칙

- 사용자는 빠르게 학습을 시작할 수 있어야 한다.
- 학습은 가능한 한 타이핑 중심이어야 한다.
- 게임처럼 보이는 기능도 학습 효과가 우선이다.
- 단어 데이터와 학습 기록은 업데이트 때 최대한 보존한다.
- 복잡한 계정/서버 구조 없이 로컬 저장 기반으로 동작한다.

### 1.2 현재 플랫폼

- iOS / Android 앱
- HTML / CSS / JavaScript 기반
- Capacitor 8 사용
- PWA 테스트는 보조 용도이며, 최종 판단은 실기기 앱 기준으로 한다.

### 1.3 현재 앱 버전 성격

- 서버 없음
- 로그인 없음
- 학습 상태는 기기 localStorage에 저장
- 네이티브 기능은 Capacitor plugin을 통해 사용
  - Text to Speech
  - Haptics
  - Local Notifications
  - App back button handling
  - Native share / image save 관련 기능

## 3. 핵심 화면 구조

### 3.1 하단 탭

현재 앱의 주요 탭은 다음과 같다.

- Home
- Study
- Drill
- Words
- Settings

상단 타이틀 영역과 하단 네비게이션은 화면 위계를 만든다. 앱 배경은 연한 회색, 카드/콘텐츠 영역은 흰색을 기본으로 한다.

### 3.2 Home

Home은 학습 설정 화면이 아니라 상태 확인 화면이다.

주요 구성:

- Attendance
- CEFR vocabulary progress

학습 설정은 Study 탭으로 이동되어 있다.

### 3.3 Study

정규 학습 진입 화면이다.

주요 구성:

- 학습 카드
- 학습 모드 선택
- 목표 단어 수
- CEFR 선택
- 카테고리 선택
- 새 단어 세트 버튼

정규 학습이 시작되면 학습 설정은 숨긴다. 학습 초기 상태로 돌아오면 다시 표시한다.

### 3.4 Drill

훈련소 탭이다.

주요 구성:

- 훈련 대상 선택
  - Wrong answers
  - Hard words
  - Bookmarks
- Drill mode
  - Cram
  - Word Drop
- Number of words
- Start drill session

훈련소 설명 문구는 과도한 설명을 줄이기 위해 제거했다.

### 3.5 Words

단어 관리 탭이다.

주요 구성:

- Wrong answers
- Hard words
- Bookmarks
- Search

불필요한 설명 문구는 제거하고, 사용자가 바로 목록/검색에 접근하도록 한다.

### 3.6 Settings

주요 구성:

- Language settings
- Sound / Haptics
- Study reminder
- Feedback button

Study reminder는 네이티브 앱에서만 실제 알림이 동작한다. PWA에서는 UI 확인 정도만 가능하다.

## 4. 학습 모드

### 4.1 모드 종류

정규 학습 모드:

- Card
- Copy
- Typing

훈련소 모드:

- Cram
- Word Drop

### 4.2 Card

단어를 먼저 보고 정답 화면에서 뜻과 추가 정보를 확인하는 모드다.

SRS 반영:

- 정답 확인 후 난이도 선택으로 SRS 상태를 업데이트한다.

### 4.3 Copy

정답을 보며 따라 쓰는 모드다.

현재 정책:

- 입력값이 정답과 일치하면 엔터 없이 자동 판정한다.
- 정답 화면에서 로마니제이션/후리가나/핑잉/읽기 보조 정보가 필요한 언어는 표시한다.
- 질문 화면에는 읽기 보조 정보를 노출하지 않는다.

### 4.4 Typing

뜻을 보고 학습 언어 단어를 입력하는 recall 중심 모드다.

현재 정책:

- 힌트 버튼 제공
- 힌트는 고스트 텍스트 형태로 앞글자부터 점진적으로 보여준다.
- 관사가 있는 언어에서는 관사 전체가 힌트를 소모하지 않도록 처리한다.
- 힌트를 사용하면 Easy 난이도는 비활성화한다.
- Typing은 아직 완전 자동 판정보다는 사용자가 확인/정답 확인 흐름을 제어할 수 있게 둔다.

### 4.5 Cram

훈련소에서 선택한 단어를 반복 타이핑하는 모드다.

현재 정책:

- 틀린 단어, 어려운 단어, 북마크 단어 중심
- 정답 입력 시 자동 판정
- 정답이면 다음 단계로 이동
- 일부 상황에서는 다음 문제로 넘어가기 위한 버튼을 유지한다.
- 학습 완료 후 훈련소 흐름으로 복귀한다.

### 4.6 Word Drop

타이핑 기반 recall 훈련 게임 모드다.

핵심 UX:

- 입력창을 터치해 키보드가 올라오면 카운트다운 후 시작한다.
- 단어 하나만 위에서 아래로 떨어진다.
- 단어는 3개 lane 중 하나에서 랜덤으로 나온다.
- 입력값이 정답과 일치하면 즉시 제거된다.
- 단어가 바닥에 닿으면 missed로 처리된다.
- 목표 단어 수를 채우면 종료된다.

현재 정책:

- life 시스템은 사용하지 않는다.
- 사용자가 선택한 단어 수만큼 진행한다.
- 속도는 현재 아레나 크기와 모바일 입력성을 고려해 고정 기본 속도를 사용한다.
- 성공한 단어는 MVP에서 SRS에 반영하지 않는다.
- 실패한 단어도 기존 mistakes에 직접 추가하지 않고, 세션 결과의 missed로 소비한다.
- 종료 화면에서 missed 단어를 복습할 수 있다.
- 맞춘 순간 TTS가 재생된다.

Word Drop 단어 선택:

- 기본 풀은 현재 학습 언어의 단어다.
- 일반 단어는 현재 선택 CEFR, 가장 많이 학습한 CEFR, 최근 학습 CEFR을 고려한다.
- 점수 구간별 비율:
  - score < 10: normal 80%, mistake 15%, bookmark 5%
  - score < 30: normal 60%, mistake 30%, bookmark 10%
  - score >= 30: normal 45%, mistake 40%, bookmark 15%
- mistake/bookmark 풀이 비어 있으면 normal/all 풀로 fallback한다.
- 직전 3개 단어는 가능하면 반복하지 않는다.

### 5.1 정규 학습 큐

정규 학습 큐는 다음 조건으로 구성한다.

### 5.2 단어 세트 유지

현재 정책:

- 한 번 뽑힌 정규 학습 단어 세트는 유지한다.
- 사용자가 모드를 바꿔도 같은 단어 세트로 다시 학습할 수 있게 한다.
- 새 단어 세트는 사용자가 `New word set` 버튼을 눌렀을 때만 뽑는다.

관련 저장소:

- `STORAGE_KEYS.STUDY_WORD_SET = "karllang_study_word_set_v1"`

## 6. SRS / 통계 / 단어 상태

### 6.1 SRS 기본 원칙

SRS는 정규 학습 결과를 기준으로 반영한다.

Word Drop 성공은 SRS에 바로 반영하지 않는다. 속도 게임에서 맞춘 것과 정규 학습에서 맞춘 것은 학습 신뢰도가 다르기 때문이다.

### 6.2 localStorage 키

현재 주요 storage key:

```js
STORAGE_KEYS = {
  SETTINGS: "karllang_settings_v3",
  SRS_PREFIX: "karllang_word_",
  STATS: "karllang_stats_v4",
  WORD_STATS: "karllang_word_stats_v4",
  DAILY_SUMMARY: "karllang_daily_summary_v1",
  ATTENDANCE: "karllang_attendance_v1",
  STUDY_WORD_SET: "karllang_study_word_set_v1",
  USER_DATA_SCHEMA: "karllang_user_data_schema_v1",
}
```

### 6.3 업데이트와 데이터 보존 정책

현재 정책:

- `APP_VERSION`은 UI/기능 업데이트 추적용이다.
- `DATA_VERSION`은 단어 데이터 버전 추적용이다.
- 앱 업데이트만으로 학습 기록을 초기화하지 않는다.
- 데이터 버전이 바뀌어도 기본은 migration/보존이다.
- 단어 ID 체계가 깨지는 경우에만 리셋을 고려한다.
- 기존 유저의 SRS, bookmark, mistake, stats 기록은 가능한 한 유지한다.

현재 값:

```js
APP_VERSION = "1.0.0"
DATA_VERSION = "karllang_words_v1_1_20260509"
USER_DATA_SCHEMA_VERSION = "2"
```

## 11. 단어 데이터 정책

### 11.1 Word schema

현재 기준 schema는 `docs/KarlLang_Schema_v1.txt`를 따른다.

핵심 원칙:

- 각 word는 안정적인 `id`를 가진다.
- 업데이트 때 ID를 함부로 바꾸지 않는다.
- `meanings`는 대표뜻 1개를 원칙으로 한다.
- 관사가 필요한 언어의 명사는 의미 표시에서도 관사를 포함한다.
- 영어 동사 뜻은 `to ...` 형태를 피한다.
- 읽기 보조 정보는 질문 화면이 아니라 정답 화면에서 보여준다.

### 11.2 단어 작업 위치

앱 repo에는 최종 앱 데이터만 둔다.

단어 추출/보강/검수 도구는 앱 repo 밖에서 관리한다.

현재 위치:

```txt
/Users/karl/Project/karl-tools/karllang-app-tools/
```

임시 API 요청/응답 로그는 앱 repo에 보관하지 않는다.

## 14. 개발 규칙

- UI/기능 업데이트는 학습 기록을 초기화하지 않는다.
- 단어 ID 변경은 최후의 수단이다.
- 단어 데이터 작업은 앱 repo가 아니라 `karl-tools`에서 한다.
- 앱 repo에는 실제 앱 실행/배포에 필요한 파일만 남긴다.
- 기능 수정과 리팩터링은 가능한 한 분리해서 커밋한다.
- 모바일 실기기 동작을 최종 기준으로 판단한다.
