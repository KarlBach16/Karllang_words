# KarlLang 작업일지

## 2026-04-29 - 학습 완료 화면 개선

### 목적

- 세션 종료 화면을 단순 결과 표시가 아니라 다음 행동을 유도하는 화면으로 개선했다.
- "실력 평가"가 아니라 "오늘 얼마나 학습했고, 지금 어떤 단어를 다시 보면 좋은지"를 보여주는 방향으로 정리했다.

### 주요 변경

- 학습 완료 화면을 두 개의 프레임으로 분리했다.
  - `오늘 요약`
  - `어려웠던 단어`
- `오늘 요약`은 하루 누적 기준으로 표시하도록 변경했다.
  - 학습 단어
  - 새로 배운 단어
  - 복습 단어
  - 타이핑 세션: 정답 / 오답
  - 카드, 따라쓰기 세션: 어려움 / 보통 / 쉬움
- `어려웠던 단어`는 현재 세션 기준으로 유지했다.
- 어려웠던 단어 목록은 최대 5개까지만 표시하고, 초과분은 `외 n개` 형태로 표시하도록 했다.
- `틀린 단어 연습` 문구를 `어려운 단어 연습`으로 변경했다.
- `어려운 단어 연습`은 훈련소/깜지 모드가 아니라 현재 세션의 어려웠던 단어를 따라쓰기 1회로 연습하게 했다.
- 어려운 단어 연습 종료 후 학습 시작 화면으로 복귀하도록 했다.
- 어려운 단어 연습 종료 후 기존 세션 단어셋 캐시를 비워 다음 시작 시 새 단어셋이 구성되도록 했다.

### UI 정리

- 완료 화면 제목에 초록 체크를 추가했다.
- 요약 프레임과 어려웠던 단어 프레임을 분리형 카드 UI로 구성했다.
- 요약 항목은 라벨 왼쪽, 숫자 오른쪽 정렬로 변경했다.
- 카드/따라쓰기 세션의 난이도 숫자에 색상을 적용했다.
  - 어려움: 빨강
  - 보통: 회색
  - 쉬움: 초록
- `다시 시작`, `어려운 단어 연습` 버튼 폭을 학습 화면의 `확인`/`정답` 버튼 폭과 맞췄다.
- 어려웠던 단어 프레임 내부는 좌측 정렬로 맞췄다.

### TTS 수정

- macOS 브라우저 Web Speech API에서 기존 발음을 `cancel()`하고 새 발음을 시작할 때 발생할 수 있는 `canceled`, `interrupted` 이벤트를 실제 오류로 보지 않도록 수정했다.
- 실제 발음은 정상 재생되는데 "이 기기에서는 발음 기능이 제한될 수 있습니다" 경고가 뜨는 문제를 줄였다.

### 번역

- 오늘 작업한 학습 완료 화면 신규 문구를 지원 UI 언어에 추가했다.
  - ko
  - en
  - de
  - es
  - fr
  - it
  - pt
  - ja
  - zh
  - ru
- `외 n개` 표시는 하드코딩을 제거하고 기존 `common_list_more` 번역 키를 사용하도록 변경했다.

## 2026-05-06 - Word Drop 모바일 시작 UX와 단어 풀 조정

### 목적

- 모바일에서 Word Drop 시작 직후 키보드가 늦게 올라오며 arena 크기가 갑자기 줄어드는 문제를 줄였다.
- 작은 모바일 arena에서 단어가 너무 빠르게 떨어져 입력 불가능해지는 상황을 방지했다.
- Word Drop의 일반 랜덤 단어가 학습자 수준과 어긋나지 않도록 조정했다.

### 시작 UX

- Word Drop 시작 직후 바로 단어를 떨어뜨리지 않도록 변경했다.
- arena 중앙에 `입력창을 터치하세요` 안내를 표시한다.
- 입력창 focus 후 키보드가 올라온 상태에서 `3 → 2 → 1` 카운트다운을 표시한다.
- 카운트다운이 끝난 뒤 첫 단어와 animation loop를 시작한다.
- 시작 대기 중 blur가 발생하면 카운트다운을 취소하고 다시 입력창 터치 안내로 돌아간다.
- 시작/종료/이탈 시 pending timer, countdown timer, RAF를 정리하도록 했다.

### 속도

- 기존 Word Drop 속도는 점수와 경과 시간에 따라 증가했다.
- 모바일 입력 환경에서는 긴 단어가 나오면 속도 증가가 학습 난이도보다 입력 불가능 문제로 이어질 수 있어 MVP 기준으로 고정 속도로 변경했다.
- `WORD_DROP_BASE_SPEED = 48`을 기준 속도로 두고, 각 단어는 동일한 속도로 떨어지게 했다.

### 단어 선택

- 기존 일반 단어 fallback 풀은 현재 학습 언어 전체 단어에서 랜덤으로 구성됐다.
- 이제 일반 단어 풀은 다음 기준을 합쳐 구성한다.
  - 현재 학습 설정의 CEFR 레벨
  - 가장 많이 학습한 CEFR 레벨
  - 최근 학습한 CEFR 레벨
- 학습 기록이 없으면 기본 `A1` 풀로 시작한다.
- 오답/북마크 단어는 약점 훈련 성격이 있으므로 레벨 제한 없이 유지한다.
- 오답/북마크 풀이 비어 일반 단어로 fallback될 때도 학습자 수준에 맞는 일반 풀을 우선 사용한다.

### 번역

- Word Drop 시작 안내 문구를 지원 UI 언어에 추가했다.
  - ko
  - en
  - de
  - es
  - fr

  - pt
  - ja
  - zh
  - ru

## 2026-05-04 - 앱 업데이트 시 학습기록 보존

### 목적

- 앱 업데이트 후 SRS, 북마크, 틀린 단어, 전체 통계가 초기화될 수 있는 문제를 수정했다.
- 서버 저장소를 붙이기 전까지 localStorage 기반 학습기록을 최대한 안정적으로 유지하도록 했다.

### 원인

- 기존에는 `SETTINGS.dataVersion !== DATA_VERSION`일 때 현재 학습 언어의 데이터를 바로 삭제했다.
  - SRS 기록
  - 전체 학습 통계
  - 단어별 통계, 북마크, 오답 기록
- 이 구조에서는 단순 UI 업데이트나 기능 추가 과정에서 `DATA_VERSION` 문자열이 바뀌기만 해도 유저 학습기록이 초기화될 수 있었다.

### 변경

- `APP_VERSION`과 `DATA_VERSION`을 분리했다.
- `APP_VERSION`은 UI/기능 업데이트 추적용으로만 사용하고, 학습기록 리셋 조건으로 쓰지 않게 했다.
- `DATA_VERSION`이 바뀌어도 기본 동작은 학습기록 보존으로 변경했다.
- 단어 ID 체계가 실제로 깨지는 변경만 `shouldResetLearningDataForDataVersion()`에 명시해 선택적으로 리셋하도록 했다.
- 기존 저장 구조를 최대한 살리는 localStorage migration을 추가했다.
  - `karllang_stats_v3` → `karllang_stats_v4`
  - `karllang_word_stats_v3` → `karllang_word_stats_v4`
  - 단일언어 flat stats 구조 → 현재 언어별 stats 구조
- migration 실행 여부를 추적하기 위한 user data schema 키를 추가했다.

### 보존 대상

- 단어별 SRS 진행도
- 북마크
- 틀린 단어/어려운 단어 통계
- 전체 학습 통계
- 일일 요약과 출석 데이터

### 검증

- `node --check www/script.js`
- `node --check www/translations.js`
- `git diff --check`

## 2026-05-04 - Word Drop 훈련 모드 MVP 마감 정리

### 목적

- 훈련소에 Word Drop 훈련 모드를 추가하고 MVP 수준의 사용감을 정리했다.
- 단어를 빠르게 입력하는 recall 훈련으로 만들되, 정식 SRS 진도에는 직접 반영하지 않도록 했다.

### 진입 구조

- 훈련소의 `훈련 모드` 드롭다운에 `Word Drop`을 추가했다.
- 별도 버튼을 만들지 않고 기존 `훈련 세션 시작` 흐름을 재사용했다.
- 기존 학습 화면을 재사용하지 않고 `wordDropView` 독립 화면으로 구성했다.

### 게임 루프

- 단어 1개만 위에서 아래로 떨어지도록 구현했다.
- `requestAnimationFrame` 기반으로 위치를 갱신한다.
- 입력값이 현재 단어와 일치하면 즉시 정답 처리한다.
- 단어가 바닥에 닿으면 세션 내 놓친 단어로 기록한다.
- life 방식은 제거하고, 훈련소의 단어 수 선택값만큼 진행하는 목표 개수 기반으로 변경했다.

### 단어 선택

- 전체 단어, 기존 오답 단어, 북마크 단어 풀을 사용한다.
- 점수에 따라 일반/오답/북마크 단어 비율이 바뀌도록 했다.
- 오답/북마크 풀이 부족하면 일반 단어로 fallback한다.
- 직전 3개 단어는 가능하면 다시 나오지 않게 했다.
- Word Drop에서 맞춘 단어는 SRS 레벨을 올리지 않는다.
- Word Drop에서 놓친 단어도 전역 mistakes에는 바로 저장하지 않고, 세션 내 복습 대상으로만 사용한다.

### UX 조정

- 하단 네비게이션은 Word Drop 플레이 중 숨기고, 종료 후 다시 보이도록 했다.
- 모바일 키보드가 올라올 때 `visualViewport` 기준으로 화면 높이를 보정했다.
- 진행 상태는 상단 숫자 HUD 대신 얇은 progress bar로 표시했다.
- 단어는 좌/중/우 3개 레인 중 랜덤 위치에서 떨어지게 했다.
- 좌우 레인의 긴 단어가 프레임 밖으로 잘리지 않도록 x 위치를 보정했다.
- 정답 시 단어가 현재 위치에서 팝 효과로 사라지게 했다.
- 놓친 경우 입력창만 짧게 붉은색으로 표시한다.
- 종료 화면에서 입력값이 남지 않도록 정리했다.

### 복습 흐름

- 종료 화면의 `복습하기` 버튼은 단어장으로 이동하지 않고, Word Drop에서 놓친 단어만 복습 세션으로 보낸다.
- Word Drop 복습이 끝나면 학습 화면이 아니라 훈련소 화면으로 돌아오게 했다.

### 번역/문구

- 훈련 모드 이름과 설명을 지원 UI 언어 전체에 추가했다.
- Word Drop 종료 화면, 결과 문구, 입력창 placeholder, 버튼 문구를 지원 UI 언어 전체에 추가했다.
- Word Drop 설명은 훈련소 기본 컨셉과 중복되지 않게 짧게 정리했다.

### 검증

- `node --check www/translations.js`
- `git diff --check`

## 2026-04-30 - Firebase Analytics 이벤트 정리

### 목적

- Firebase Analytics 이벤트를 실제 사용자 행동 중심으로 정리했다.
- 테스트 이벤트와 자동 렌더링에서 발생할 수 있는 불필요한 이벤트를 제거했다.
- 세션 시작/완료, 언어 변경, 하단 탭 이동처럼 제품 판단에 필요한 이벤트만 남겼다.

### 이벤트 정리

- `test_event` 호출이 남아 있지 않은지 확인했다.
- 기존 `logEvent` 직접 호출을 `logAnalyticsEvent` 래퍼로 정리했다.
- Firebase/NativeAnalytics가 없어도 앱이 죽지 않도록 네이티브 플러그인 존재 여부를 확인한 뒤 이벤트를 보낸다.
- 단어 ID는 Firebase로 보내지 않도록 유지했다.
- 문제 하나마다 이벤트를 보내는 로직은 추가하지 않았다.
- `applyTranslations`, `hydrateSettingsToUI` 같은 자동 UI 동기화 함수에서는 이벤트를 보내지 않도록 유지했다.

### 세션 이벤트

- 일반 학습 시작 버튼을 눌러 실제 학습 큐가 만들어지고, 학습할 단어가 있을 때만 `start_session`을 보낸다.

  - `study_lang`

  - `mode`
  - `cefr`
  - `category`

- `complete_session` 파라미터를 보강했다.
  - `study_lang`

  - `cefr`

  - `new_count`
  - `review_count`
  - `hard_count`
  - `normal_count`
  - `easy_count`
  - `mistake_count`

### 언어 변경 이벤트

- 기존 `select_study_language` 이벤트를 제거했다.
- 사용자가 실제 select를 변경했을 때만 언어 변경 이벤트를 보내도록 했다.
- UI 언어 변경은 `change_ui_language`로 기록한다.
- 학습 언어 변경은 `change_study_language`로 기록한다.
- 두 이벤트 모두 `from_lang`, `to_lang`만 보낸다.

### 하단 탭 이벤트

- 사용자가 하단 탭을 눌러 실제 화면 이동이 일어날 때만 `select_tab`을 보낸다.
- 같은 탭을 다시 누르는 경우에는 이벤트를 보내지 않도록 했다.
- 탭 값은 다음 중 하나로 제한했다.

## 2026-04-29 - 홈 출석 카드와 상태 프레임 정리

### 목적

- 홈탭에 가벼운 출석 표시를 추가해 학습 습관을 조용하게 보여주도록 했다.
- 홈/완료/훈련소 화면의 정보 묶음 UI를 프레임 카드 문법으로 맞춰 화면 위계를 정리했다.

### 출석 기능

- 홈탭의 `학습 설정` 아래, `CEFR 단어 진척도` 위에 출석 카드를 추가했다.
- 출석 기준은 앱 접속이 아니라 일반 학습 `시작` 버튼 클릭으로 정했다.
- 하루 1회만 기록되도록 했다.

### 훈련소 UI

- `훈련 대상` 토글 3개를 하나의 프레임으로 묶었다.
  - 틀린 단어
  - 어려운 단어

- 토글 각각은 카드화하지 않고, 전체 대상 선택 그룹만 프레임으로 묶었다.
- `훈련 대상` 제목은 row 라벨과 구분되도록 더 굵고 크게 조정했다.

### 보류한 아이디어

- 추후 추가한다면 같은 주 1회만, 짧은 성공 진동과 차분한 메시지 정도가 적합하다.

## 2026-04-29 - 햄버거 메뉴 제거와 하단 탭 전환

### 목적

- 햄버거 메뉴에 숨어 있던 주요 기능을 하단 탭으로 노출해 접근성을 높였다.
- KarlLang의 주요 화면을 모바일 앱에 맞는 고정 탭 구조로 재정리했다.

### 주요 변경

- 기존 햄버거 메뉴를 제거하고 하단 탭 5개로 전환했다.
  - 홈
  - 학습
  - 훈련
  - 단어
  - 설정
- 탭은 텍스트만 쓰지 않고 미니멀한 라인 아이콘과 짧은 라벨 조합으로 구성했다.
- 아이콘은 별도 컬러 장식 없이 현재 활성 색상만 따라가도록 했다.
- 활성 탭은 앱에서 쓰는 파란색 계열로 표시되게 했다.

### 단어 탭

- `단어` 탭은 바로 어려운 단어 목록으로 이동하지 않고, 단어 허브 화면으로 이동하도록 했다.
- 단어 허브 안에 세 가지 진입점을 배치했다.
  - 어려운 단어
  - 북마크
  - 검색
- 어려운 단어, 북마크, 검색 하위 화면에 들어가도 하단 탭에서는 `단어`가 활성화되도록 처리했다.
- 단어 허브 문구를 지원 UI 언어 전체에 추가했다.

### 햄버거 메뉴 정리

- 햄버거 버튼 DOM을 제거했다.
- 사이드 메뉴와 오버레이 DOM을 제거했다.
- 사이드 메뉴 관련 CSS를 제거했다.
- 사이드 메뉴 열기/닫기 함수와 이벤트 바인딩을 제거했다.
- 사이드 메뉴 터치 피드백 코드도 제거했다.
- 제거 후 남은 햄버거/사이드 메뉴 참조가 없는지 검색으로 확인했다.

### Android 뒤로가기

- 기존 Android back button 처리는 유지하되, 새 하단 탭 구조에 맞게 흐름을 조정했다.
- 뒤로가기 동작은 다음 순서로 처리한다.
  - 단어 상세 팝업이 열려 있으면 팝업 닫기
  - 학습 진행 중이면 확인 후 학습 시작 상태로 복귀
  - 어려운 단어/북마크/검색 화면이면 단어 허브로 복귀
  - 다른 탭이면 학습 탭으로 이동
  - 학습 READY 상태에서는 두 번 눌러 앱 종료

### 검색/드롭다운 UI 정리

- 단어 검색 화면의 `검색 기준` 영역 간격을 조정했다.
- 검색 기준 라벨과 드롭다운을 가로 정렬로 정리했다.
- 검색 화면에만 적용되도록 `#searchView` 범위 스타일로 제한했다.
- 드롭다운 포커스 테두리가 화면마다 다르게 보이던 문제를 수정했다.
- select 공통 스타일에 박스 모델을 통일하고, 포커스 시 전체 테두리와 링이 고르게 보이도록 했다.

### 실기기 하단 탭 조정

- PWA/실기기에서 하단 탭 아래 여백이 과하게 보이는 문제를 수정했다.
- 하단 탭 높이를 `60px` 기준으로 정리했다.
- 하단 탭 자체에 `safe-area-inset-bottom`이 중복으로 반영되던 구조를 제거했다.
- 콘텐츠가 탭에 가려지지 않도록 본문 스크롤 영역에만 하단 여백을 남겼다.

### 단어 목록 스크롤 수정

- 어려운 단어/북마크/검색 화면에서 긴 목록이 나올 때 하단 탭 위치가 내려가 보이는 문제를 수정했다.
- 하단 탭을 뷰포트 `fixed`가 아니라 앱 컨테이너 내부 `absolute`로 고정했다.
- `#app`은 `100dvh` 높이와 `overflow: hidden` 구조로 고정했다.
- 실제 스크롤은 `.app-main` 하나만 담당하도록 정리했다.
- 단어 목록의 별도 내부 스크롤을 제거해 중첩 스크롤을 없앴다.

## 2026-04-30 - 온보딩 언어 선택 화면과 설정 피드백 버튼 정리

### 목적

### 언어 선택 화면

- 인트로에서 이미 앱 이름과 아이콘을 보여주므로 언어 선택 화면의 `KarlLang` 제목을 제거했다.

### 설정 화면

- 버튼을 설정 화면 하단, 하단 탭 바로 위쪽으로 이동했다.
