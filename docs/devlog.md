# KarlLang 작업일지

## 2026-05-07 - 네이티브 학습 알림 MVP

### 목적

- KarlLang의 학습 루프를 강화하기 위해 하루 1회 상기성 알림을 추가했다.
- 강한 압박형 알림이 아니라, 기억 유지와 recall을 떠올리게 하는 조용한 알림으로 설계했다.
- PWA는 실기기 확인용 UI만 제공하고, 실제 알림 예약은 네이티브 앱에서만 동작하도록 했다.

### 로컬 알림 플러그인

- `@capacitor/local-notifications`를 추가했다.
- `npx cap sync`로 Android/iOS 네이티브 프로젝트에 플러그인 연결을 반영했다.
- Android Gradle 설정에 local notifications 플러그인이 포함되도록 갱신했다.
- iOS SwiftPM 패키지 설정에 `CapacitorLocalNotifications`를 추가했다.

### 설정 UI

- 설정탭의 피드백 설정 카드에 `학습 알림` 토글을 추가했다.
- `알림 시간` 설정을 추가했다.
- 처음에는 OS 기본 `input type="time"`을 사용했으나, 브라우저/OS 로케일에 따라 `오전/오후` 표기와 시계 아이콘이 섞이는 문제가 있어 직접 만든 `select` 드롭다운으로 변경했다.
- 시간 선택지는 30분 단위로 생성한다.
- 표시 형식은 UI 언어와 무관하게 `AM 08:30`, `PM 08:30` 형태로 통일했다.
- PWA에서도 UI 형태를 확인할 수 있도록 알림 토글과 시간 선택을 그대로 노출한다.
- PWA에서 토글을 켜면 실제 예약은 하지 않고 앱에서만 사용할 수 있다는 안내를 보여준다.

### 학습 세트 전환

- 학습 설정 카드 하단에 `새 단어 세트` 보조 버튼을 추가했다.
- 같은 조건에서 모드만 바꿔 학습할 때는 기존 단어 세트를 유지하는 흐름은 유지했다.
- 사용자가 다른 단어 묶음을 원할 때만 `새 단어 세트` 버튼으로 현재 세트 캐시를 비울 수 있게 했다.
- 버튼을 누르면 다음 `시작` 때 새 학습 큐를 뽑는다.
- 버튼 문구와 안내 토스트를 지원 UI 언어에 추가했다.

### 알림 동작

- 알림 기본값은 OFF다.
- 사용자가 ON으로 바꾸면 네이티브 앱에서 알림 권한을 요청한다.
- 권한이 허용되면 사용자가 선택한 시간에 매일 반복되는 로컬 알림을 예약한다.
- OFF로 바꾸면 예약된 알림을 취소한다.
- 알림 시간이 변경되면 기존 예약을 취소하고 새 시간으로 재예약한다.
- 앱 시작 시 알림 설정이 켜져 있으면 기존 설정 시간으로 예약을 보정한다.

### 문구 방향

- 알림 본문은 `공부하세요`보다 기억 유지에 초점을 맞췄다.
- 기본 한국어 문구:
  - `기억은 생각보다 빨리 흐려져요. 오늘 단어를 한 번만 다시 붙잡아보세요.`

### 번역

- 알림 설정/권한/시간/알림 본문 문구를 지원 UI 언어에 추가했다.

  - ru

## 2026-05-06 - 학습 흐름/공유 카드/타이포 후속 정리

### 목적

- 학습 설정을 실제 학습 흐름에 더 가깝게 배치했다.
- 공유 이미지 카드의 지표를 더 공유할 만한 성취 중심으로 바꿨다.
- 앱 전체 카드 간격과 텍스트 위계를 정리해 화면을 더 또렷하게 보이도록 했다.

### 학습 설정 위치와 흐름

- 홈 화면에 있던 학습 설정 카드를 학습탭으로 이동했다.
- 학습 카드는 기존처럼 먼저 보이게 유지하고, 학습 설정은 학습 카드 아래에 배치했다.
- 학습 설정 카드의 `학습 설정` 제목은 제거해 화면 밀도를 낮췄다.
- 학습 설정 카드는 학습 시작 전 `READY` 상태에서만 보이게 했다.
- 학습 중, 정답 화면, 완료 화면에서는 학습 설정 카드가 숨겨지도록 했다.
- 완료 후 `다시 시작`으로 첫 화면에 돌아오면 학습 설정 카드가 다시 보이도록 했다.

### 학습 세트 재사용

- 학습 완료 후 `다시 시작`을 눌러도 오늘 생성된 단어 세트 캐시를 비우지 않도록 변경했다.
- 같은 날, 같은 학습 언어, 같은 레벨/카테고리 조건에서는 모드를 바꿔 다시 시작해도 같은 단어 세트를 재사용한다.
- 카드 모드로 한 세트를 본 뒤 타이핑/따라쓰기 모드로 같은 세트를 다시 학습할 수 있게 했다.

### 공유 이미지 카드

- 공유 카드의 핵심 지표를 다음 3개로 변경했다.
  - 학습 단어
  - 정답률
  - 연속 학습
- 정답률은 오늘 학습 요약의 `correct / total` 기준으로 계산한다.
- 연속 학습은 기존 출석 기록을 기반으로 오늘 기준 streak를 계산한다.
- 공유 카드 제목의 `회상` 표현을 제거하고 `오늘의 단어 훈련` 계열 문구로 정리했다.
- 상단의 굵은 초록색 바를 얇은 파란색 라인으로 바꿨다.
- 하단 문구가 버튼처럼 보이지 않도록 초록색 pill 형태를 제거하고 얇은 구분선과 텍스트로 변경했다.

### UI 간격과 타이포

- 홈 첫 카드인 출석 카드와 상단 제목 영역 사이 간격을 다른 탭과 맞췄다.
- 홈의 `출석` 카드와 `CEFR 진척도` 카드 사이 간격을 12px 기준으로 정리했다.
- 훈련소/설정/학습 설정 카드 간격도 같은 톤으로 맞췄다.
- 폰트 패밀리는 유지하고, 크기/굵기/줄간격만 조정했다.
- 상단 탭 제목, 학습 질문, 카드 제목류를 더 굵고 선명하게 조정했다.
- 설정/훈련소 라벨은 작게 유지하되 굵기를 올려 가독성을 개선했다.
- 버튼은 살짝 컴팩트하게 조정했다.

### PWA/네이티브 키보드 보정

- 일반 학습/크램에서 키보드가 올라올 때 하단 네비를 숨기는 처리를 네이티브 플랫폼에만 적용하도록 분리했다.
- PWA에서는 출시 버전과 다르게 보일 수 있는 키보드/하단 탭 차이를 과하게 보정하지 않도록 했다.

## 2026-04-29 - 학습 완료 화면 개선

### 목적

- 세션 종료 화면을 단순 결과 표시가 아니라 다음 행동을 유도하는 화면으로 개선했다.
- "실력 평가"가 아니라 "오늘 얼마나 학습했고, 지금 어떤 단어를 다시 보면 좋은지"를 보여주는 방향으로 정리했다.

### 주요 변경

- 학습 완료 화면을 두 개의 프레임으로 분리했다.
  - `오늘 요약`
  - `어려웠던 단어`
- `오늘 요약`은 하루 누적 기준으로 표시하도록 변경했다.
  - 학습 단어
  - 새로 배운 단어
  - 복습 단어
  - 타이핑 세션: 정답 / 오답
  - 카드, 따라쓰기 세션: 어려움 / 보통 / 쉬움
- `어려웠던 단어`는 현재 세션 기준으로 유지했다.
- 어려웠던 단어 목록은 최대 5개까지만 표시하고, 초과분은 `외 n개` 형태로 표시하도록 했다.
- `틀린 단어 연습` 문구를 `어려운 단어 연습`으로 변경했다.
- `어려운 단어 연습`은 훈련소/깜지 모드가 아니라 현재 세션의 어려웠던 단어를 따라쓰기 1회로 연습하게 했다.
- 어려운 단어 연습 종료 후 학습 시작 화면으로 복귀하도록 했다.
- 어려운 단어 연습 종료 후 기존 세션 단어셋 캐시를 비워 다음 시작 시 새 단어셋이 구성되도록 했다.

### UI 정리

- 완료 화면 제목에 초록 체크를 추가했다.
- 요약 프레임과 어려웠던 단어 프레임을 분리형 카드 UI로 구성했다.
- 요약 항목은 라벨 왼쪽, 숫자 오른쪽 정렬로 변경했다.
- 카드/따라쓰기 세션의 난이도 숫자에 색상을 적용했다.
  - 어려움: 빨강
  - 보통: 회색
  - 쉬움: 초록
- `다시 시작`, `어려운 단어 연습` 버튼 폭을 학습 화면의 `확인`/`정답` 버튼 폭과 맞췄다.
- 어려웠던 단어 프레임 내부는 좌측 정렬로 맞췄다.

### TTS 수정

- macOS 브라우저 Web Speech API에서 기존 발음을 `cancel()`하고 새 발음을 시작할 때 발생할 수 있는 `canceled`, `interrupted` 이벤트를 실제 오류로 보지 않도록 수정했다.
- 실제 발음은 정상 재생되는데 "이 기기에서는 발음 기능이 제한될 수 있습니다" 경고가 뜨는 문제를 줄였다.

### 번역

- 오늘 작업한 학습 완료 화면 신규 문구를 지원 UI 언어에 추가했다.
  - ko
  - en
  - de
  - es
  - fr
  - it
  - pt
  - ja
  - zh
  - ru
- `외 n개` 표시는 하드코딩을 제거하고 기존 `common_list_more` 번역 키를 사용하도록 변경했다.

## 2026-05-06 - 공유 이미지 카드 MVP와 학습 UI 다듬기

### 목적

- 학습 완료 결과를 사용자가 공유 가능한 이미지 카드로 만들 수 있게 했다.
- 완료 화면의 정보 위계를 해치지 않도록 공유 기능을 보조 액션과 모달 구조로 정리했다.
- 따라쓰기와 다국어 읽기 보조 표시의 위치를 학습 흐름에 맞게 조정했다.

### 공유 이미지 카드

- 학습 완료/Word Drop 종료 시 오늘의 학습 요약을 기반으로 공유 이미지 데이터를 생성한다.
- Canvas 직접 생성 방식으로 PNG 이미지를 만든다.
- 외부 캡처 라이브러리는 추가하지 않았다.
- 공유 카드에는 다음 정보를 담는다.
  - 학습 언어
  - 주요 학습 모드
  - 오늘 학습 단어 수
  - 정답/복습 수
  - 어려웠던 단어
  - KarlLang 브랜드 문구
- `이미지 저장`은 PNG 다운로드로 동작한다.
- Web Share API가 가능한 환경에서는 `공유하기` 버튼으로 이미지 파일 공유를 시도한다.
- 공유가 지원되지 않는 환경에서는 저장 동작으로 fallback한다.

### 완료 화면 UI

- 공유 이미지 미리보기를 완료 화면에 바로 노출하지 않도록 변경했다.
- 완료 화면에는 `공유 이미지 만들기` 버튼만 보이게 했다.
- 버튼을 누르면 별도 모달에서 이미지 미리보기와 저장/공유 버튼을 보여준다.
- 일반 학습 완료 화면에서는 `다시 시작`을 메인 액션으로 유지하고, `어려운 단어 연습`과 `공유 이미지 만들기`를 보조 액션 줄에 배치했다.
- Word Drop 종료 화면에서도 `다시 시작`을 위에 두고, `복습하기`와 `공유 이미지 만들기`를 아래 줄에 반반 배치했다.
- 공유 이미지 모달의 버튼 색을 칼랭 기본 액션 색상 체계에 맞췄다.
  - 이미지 저장: 녹색
  - 공유하기: 파란색

### 일일 요약 데이터

- 기존 일일 요약에 공유 카드용 필드를 추가했다.
  - `modeCounts`
  - `difficultWords`
- 기존 저장소 키 버전은 변경하지 않고 필드만 확장했다.
- 정규 학습, 크램, Word Drop 완료 결과가 오늘 요약에 반영되도록 했다.

### 따라쓰기/읽기 보조 표시

- 따라쓰기 입력창에서 고스트 글씨와 실제 입력 글씨의 기준선이 어긋나던 문제를 수정했다.
- 고스트 텍스트의 수직 보정을 `0px`로 맞춰 실기기 기준 정렬을 개선했다.
- 한국어 로마니제이션, 일본어 읽기, 중국어 병음, 러시아어 reading 표시를 정답 화면 기준으로 정리했다.
- 질문 화면에는 읽기 보조 정보를 표시하지 않도록 했다.
- 카드/타이핑/카피 정답 화면에서 읽기 보조 정보 위치를 통일했다.
- 카드 모드 정답 화면은 다음 순서로 표시되도록 조정했다.
  - UI 언어 뜻
  - 학습언어 단어
  - 읽기 보조 정보
- 타이핑/카피 정답 화면은 다음 순서로 표시되도록 유지했다.
  - 학습언어 단어
  - 읽기 보조 정보
  - UI 언어 뜻

## 2026-05-06 - PWA 키보드/Word Drop UX 후속 조정

### 목적

- PWA에서 safe-area와 키보드 표시 방식 때문에 하단 네비와 배경이 어색하게 보이는 문제를 줄였다.
- Word Drop의 시작 전/진행 중/종료 화면 흐름을 iPhone에서도 빠져나갈 수 있는 구조로 정리했다.
- 한국어 등 조합형 입력에서 Word Drop 정답 처리 후 마지막 글자가 남거나, 엔터/스페이스를 눌러야 넘어가는 문제를 수정했다.

### PWA 배경과 하단 영역

- PWA 하단 safe-area에 앱 배경 회색이 보이지 않도록 바깥 배경을 흰색으로 고정했다.
- `body`, `.app-card`, `.page-wrapper`는 흰색을 사용한다.
- 회색 배경은 메인 앱 콘텐츠 영역인 `#app .app-main`에만 유지한다.
- PWA `theme-color`도 흰색으로 되돌렸다.

### 키보드와 하단 네비

- 일반 학습/크램에서 키보드가 올라올 때 하단 네비가 같이 올라와 카드 영역을 가리는 문제를 줄였다.
- 키보드 입력이 필요한 학습 질문 단계에서는 `study-keyboard-active` 상태로 하단 네비를 숨긴다.
- 크램 진행 중에는 `training-cram-active` 상태로 하단 네비를 숨기고, 상단 헤더 제목을 `크램`으로 표시한다.
- 답변 상태, READY 상태, 종료 화면, 다른 탭 이동 시 네비는 다시 나타난다.

### Word Drop 시작/종료 흐름

- Word Drop 시작 전에는 하단 네비를 유지해 사용자가 바로 다른 탭으로 빠져나갈 수 있게 했다.
- 입력창을 터치해 키보드가 올라오고 카운트다운/플레이가 시작되면 하단 네비를 숨긴다.
- 키보드를 내리면 하단 네비가 다시 보이도록 했다.
- 시작 전 arena 높이를 제한해 입력창과 네비가 같이 보이도록 조정했다.
- 플레이 중에는 arena가 다시 남는 공간을 크게 쓰도록 했다.
- 종료 화면에서는 입력창을 숨긴다.
- 종료 화면 제목은 상단 헤더의 `워드 드롭`과 중복되지 않도록 `세션 종료`로 변경했다.
- 종료 상태에서 progress bar가 상단 헤더에 너무 붙지 않도록 여백을 추가했다.
- 단어가 비어 있을 때 빈 단어 pill이 보이지 않도록 `.word-drop-word:empty`를 숨겼다.

### Word Drop 조합형 입력

- 한국어 IME에서 정답 처리 후 마지막 글자가 입력창에 남는 문제를 수정했다.
- `compositionstart` / `compositionend` 이벤트를 추적한다.
- 조합형 입력에서 `compositionend`가 늦거나 스페이스/엔터 전까지 발생하지 않는 경우를 대비해, input 값이 이미 정답과 같으면 조합 중이어도 즉시 정답 처리한다.
- 정답 처리 후 짧은 clear guard를 두고 여러 타이밍에 입력창을 비워 잔여 글자가 다시 커밋되는 문제를 줄였다.
- 비교 시 `normalize("NFC")`를 적용해 조합 문자열 비교 안정성을 높였다.

## 2026-04-30 - Firebase Analytics 이벤트 정리

### 목적

- Firebase Analytics 이벤트를 실제 사용자 행동 중심으로 정리했다.
- 테스트 이벤트와 자동 렌더링에서 발생할 수 있는 불필요한 이벤트를 제거했다.
- 세션 시작/완료, 언어 변경, 하단 탭 이동처럼 제품 판단에 필요한 이벤트만 남겼다.

### 이벤트 정리

- `test_event` 호출이 남아 있지 않은지 확인했다.
- 기존 `logEvent` 직접 호출을 `logAnalyticsEvent` 래퍼로 정리했다.
- Firebase/NativeAnalytics가 없어도 앱이 죽지 않도록 네이티브 플러그인 존재 여부를 확인한 뒤 이벤트를 보낸다.
- 단어 ID는 Firebase로 보내지 않도록 유지했다.
- 문제 하나마다 이벤트를 보내는 로직은 추가하지 않았다.
- `applyTranslations`, `hydrateSettingsToUI` 같은 자동 UI 동기화 함수에서는 이벤트를 보내지 않도록 유지했다.

### 세션 이벤트

- 일반 학습 시작 버튼을 눌러 실제 학습 큐가 만들어지고, 학습할 단어가 있을 때만 `start_session`을 보낸다.
- `start_session` 파라미터를 보강했다.
  - `study_lang`
  - `ui_lang`
  - `mode`
  - `cefr`
  - `category`
  - `target_count`
- 학습 세션 완료 시 `complete_session`을 보낸다.
- `complete_session` 파라미터를 보강했다.
  - `study_lang`
  - `ui_lang`
  - `mode`
  - `cefr`
  - `category`
  - `total_count`
  - `new_count`
  - `review_count`
  - `hard_count`
  - `normal_count`
  - `easy_count`
  - `mistake_count`

### 언어 변경 이벤트

- 기존 `select_study_language` 이벤트를 제거했다.
- 사용자가 실제 select를 변경했을 때만 언어 변경 이벤트를 보내도록 했다.
- UI 언어 변경은 `change_ui_language`로 기록한다.
- 학습 언어 변경은 `change_study_language`로 기록한다.
- 두 이벤트 모두 `from_lang`, `to_lang`만 보낸다.

### 하단 탭 이벤트

- 사용자가 하단 탭을 눌러 실제 화면 이동이 일어날 때만 `select_tab`을 보낸다.
- 같은 탭을 다시 누르는 경우에는 이벤트를 보내지 않도록 했다.
- 탭 값은 다음 중 하나로 제한했다.
  - `home`
  - `study`
  - `training`
  - `words`
  - `settings`

### iOS/Android 동기화

- 실기기 테스트를 위해 Capacitor 웹 에셋을 iOS/Android 프로젝트에 동기화했다.
- iOS 버전/빌드 값은 현재 릴리스 준비 상태에 맞게 유지했다.
  - `MARKETING_VERSION = 1.2.0`
  - `CURRENT_PROJECT_VERSION = 4`

### 검증

- `node --check www/script.js`
- `git diff --check`
- `test_event`, `select_study_language` 잔여 참조 검색

## 2026-04-29 - 홈 출석 카드와 상태 프레임 정리

### 목적

- 홈탭에 가벼운 출석 표시를 추가해 학습 습관을 조용하게 보여주도록 했다.
- 홈/완료/훈련소 화면의 정보 묶음 UI를 프레임 카드 문법으로 맞춰 화면 위계를 정리했다.

### 출석 기능

- 홈탭의 `학습 설정` 아래, `CEFR 단어 진척도` 위에 출석 카드를 추가했다.
- 출석 기준은 앱 접속이 아니라 일반 학습 `시작` 버튼 클릭으로 정했다.
- 하루 1회만 기록되도록 했다.
- 훈련소 시작이나 어려운 단어 연습은 출석으로 기록하지 않도록 했다.
- 출석 표시는 월-일 점 표시만 남겼다.
  - `n일 연속 학습`
  - `이번 주 n/7일`
  - 위 두 문구는 KarlLang 톤에 비해 과한 동기부여 지표로 보여 제거했다.
- 날짜는 로컬 날짜 키(`YYYY-MM-DD`) 기준으로 저장하도록 했다.

### 홈 화면 UI

- 출석 카드에 8px radius, 흰 배경, 얇은 테두리를 적용했다.
- CEFR 진척도도 같은 프레임 카드로 감쌌다.
- CEFR 제목을 프레임 안으로 이동해 `출석`과 `CEFR 단어 진척도`가 둘 다 상태 카드처럼 보이게 정리했다.

### 훈련소 UI

- `훈련 대상` 토글 3개를 하나의 프레임으로 묶었다.
  - 틀린 단어
  - 어려운 단어
  - 북마크
- 토글 각각은 카드화하지 않고, 전체 대상 선택 그룹만 프레임으로 묶었다.
- `훈련 대상` 제목은 row 라벨과 구분되도록 더 굵고 크게 조정했다.

### 보류한 아이디어

- 출석 7일 완료 시 진동과 축하 팝업을 띄우는 아이디어를 검토했다.
- KarlLang의 조용한 학습 도구 톤에는 다소 게임화가 강하다고 판단해 보류했다.
- 추후 추가한다면 같은 주 1회만, 짧은 성공 진동과 차분한 메시지 정도가 적합하다.

### 번역

  - ko
  - en
  - de
  - es
  - fr
  - it
  - pt
  - ja
  - zh
  - ru

## 2026-04-29 - 햄버거 메뉴 제거와 하단 탭 전환

### 목적

- 햄버거 메뉴에 숨어 있던 주요 기능을 하단 탭으로 노출해 접근성을 높였다.
- KarlLang의 주요 화면을 모바일 앱에 맞는 고정 탭 구조로 재정리했다.

### 주요 변경

- 기존 햄버거 메뉴를 제거하고 하단 탭 5개로 전환했다.
  - 홈
  - 학습
  - 훈련
  - 단어
  - 설정
- 탭은 텍스트만 쓰지 않고 미니멀한 라인 아이콘과 짧은 라벨 조합으로 구성했다.
- 아이콘은 별도 컬러 장식 없이 현재 활성 색상만 따라가도록 했다.
- 활성 탭은 앱에서 쓰는 파란색 계열로 표시되게 했다.

### 단어 탭

- `단어` 탭은 바로 어려운 단어 목록으로 이동하지 않고, 단어 허브 화면으로 이동하도록 했다.
- 단어 허브 안에 세 가지 진입점을 배치했다.
  - 어려운 단어
  - 북마크
  - 검색
- 어려운 단어, 북마크, 검색 하위 화면에 들어가도 하단 탭에서는 `단어`가 활성화되도록 처리했다.
- 단어 허브 문구를 지원 UI 언어 전체에 추가했다.

### 햄버거 메뉴 정리

- 햄버거 버튼 DOM을 제거했다.
- 사이드 메뉴와 오버레이 DOM을 제거했다.
- 사이드 메뉴 관련 CSS를 제거했다.
- 사이드 메뉴 열기/닫기 함수와 이벤트 바인딩을 제거했다.
- 사이드 메뉴 터치 피드백 코드도 제거했다.
- 제거 후 남은 햄버거/사이드 메뉴 참조가 없는지 검색으로 확인했다.

### Android 뒤로가기

- 기존 Android back button 처리는 유지하되, 새 하단 탭 구조에 맞게 흐름을 조정했다.
- 뒤로가기 동작은 다음 순서로 처리한다.
  - 단어 상세 팝업이 열려 있으면 팝업 닫기
  - 학습 진행 중이면 확인 후 학습 시작 상태로 복귀
  - 어려운 단어/북마크/검색 화면이면 단어 허브로 복귀
  - 다른 탭이면 학습 탭으로 이동
  - 학습 READY 상태에서는 두 번 눌러 앱 종료

### 검색/드롭다운 UI 정리

- 단어 검색 화면의 `검색 기준` 영역 간격을 조정했다.
- 검색 기준 라벨과 드롭다운을 가로 정렬로 정리했다.
- 검색 화면에만 적용되도록 `#searchView` 범위 스타일로 제한했다.
- 드롭다운 포커스 테두리가 화면마다 다르게 보이던 문제를 수정했다.
- select 공통 스타일에 박스 모델을 통일하고, 포커스 시 전체 테두리와 링이 고르게 보이도록 했다.

### 실기기 하단 탭 조정

- PWA/실기기에서 하단 탭 아래 여백이 과하게 보이는 문제를 수정했다.
- 하단 탭 높이를 `60px` 기준으로 정리했다.
- 하단 탭 자체에 `safe-area-inset-bottom`이 중복으로 반영되던 구조를 제거했다.
- 콘텐츠가 탭에 가려지지 않도록 본문 스크롤 영역에만 하단 여백을 남겼다.

### 단어 목록 스크롤 수정

- 어려운 단어/북마크/검색 화면에서 긴 목록이 나올 때 하단 탭 위치가 내려가 보이는 문제를 수정했다.
- 하단 탭을 뷰포트 `fixed`가 아니라 앱 컨테이너 내부 `absolute`로 고정했다.
- `#app`은 `100dvh` 높이와 `overflow: hidden` 구조로 고정했다.
- 실제 스크롤은 `.app-main` 하나만 담당하도록 정리했다.
- 단어 목록의 별도 내부 스크롤을 제거해 중첩 스크롤을 없앴다.

## 2026-04-30 - 온보딩 언어 선택 화면과 설정 피드백 버튼 정리

### 목적

- 최초 설치 후 나오는 언어 선택 화면을 인트로와 역할이 겹치지 않게 정리했다.
- 설정 화면의 피드백 버튼을 주요 설정 기능과 분리해 보조 액션처럼 보이게 조정했다.

### 언어 선택 화면

- 인트로에서 이미 앱 이름과 아이콘을 보여주므로 언어 선택 화면의 `KarlLang` 제목을 제거했다.
- 언어 선택 화면의 목적이 바로 드러나도록 제목과 보조문구를 추가했다.
  - `언어 설정`
  - `앱에서 사용할 언어와 학습할 언어를 선택하세요.`
- 제목과 보조문구는 화면 상단에 따로 두지 않고, 언어 선택 카드 내부 상단으로 이동했다.
- `UI 언어`와 `학습 언어` 드롭다운을 하나의 얇은 카드 안에 묶었다.
- 디자인 확인을 위해 임시로 시작 화면 강제 노출 플래그를 사용했다.
- 확인 후 `FORCE_START_SCREEN_FOR_DESIGN` 값을 `false`로 되돌려 다시 최초 설치/온보딩 때만 언어 선택 화면이 나오도록 했다.

### 설정 화면

- 설정 화면의 `피드백 보내기` 버튼이 앱 핵심 설정과 같은 위계로 보이지 않도록 조정했다.
- 기존 전체 폭 버튼을 작은 보조 버튼으로 변경했다.
- 버튼을 설정 화면 하단, 하단 탭 바로 위쪽으로 이동했다.
- 설정 항목과 피드백 동선이 시각적으로 분리되도록 크기와 위치를 낮췄다.

## 2026-05-07 - 실기기 마무리 조정과 단어 데이터 정리

### 목적

- iOS 실기기 테스트에서 드러난 키보드, 네비게이션, 공유 이미지 저장 흐름을 정리했다.
- 학습 중 갑자기 튀어나오는 비속어/비단어성 항목을 줄여 단어 데이터 신뢰도를 높였다.

### 네이티브 기능

- 공유 이미지 저장을 네이티브 사진 보관함 저장 경로로 연결했다.
- iOS/Android용 이미지 저장 플러그인을 추가했다.
- 알림 권한이 거절된 뒤 다시 토글했을 때 앱 설정 화면으로 이동할 수 있도록 네이티브 설정 열기 플러그인을 추가했다.
- iOS 앱 표시 스타일을 light로 고정해 Word Drop 입력 중 키보드/입력창 톤이 과하게 어두워지는 문제를 줄였다.

### 학습/Word Drop UX

- 학습, 크램, 복습, 검색 입력에서 키보드가 올라올 때 상단 제목 영역이 안전 영역을 침범하지 않도록 조정했다.
- 학습 세션 중 상단 영역이 문제/정답 화면마다 오르내리지 않게 숨김 상태를 유지했다.
- Word Drop 진행 중 입력창 blur 시 하단 네비게이션을 다시 보여 탈출 경로를 확보했다.
- Word Drop 정답 순간에만 발음이 재생되도록 연결했다.
- Word Drop 카운트다운과 시작 시 하단 네비게이션이 순간적으로 보이는 현상을 줄였다.
- 학습 시작 화면의 중복 모드/CEFR 요약 문구를 제거했다.

### 공유 이미지

- 공유 이미지 미리보기 모달은 유지하되, 이미지 내부의 흰 카드 프레임을 제거해 실제 저장 이미지가 더 꽉 차 보이게 조정했다.
- 모바일 저장 안내는 네이티브 저장 경로와 맞도록 정리했다.

### 알림

- 학습 알림 권한 거절 후 재시도 흐름을 보완했다.
- 한국어 알림 문구를 더 자연스럽게 수정했다.
  - `기억은 생각보다 빨리 흐려져요. 오늘 배운 단어를 한 번만 다시 떠올려보세요.`

### 단어 데이터 정리

- 전체 언어 단어 데이터를 훑어 비속어, 모욕 표현, 욕설성 단어를 1차 제거했다.
- `put in pocket`처럼 단어가 아니라 정의문처럼 들어간 항목을 제거했다.

## 2026-05-09 - 타이핑 힌트, 훈련소 Analytics, 독일어 레벨 보정

### 타이핑 힌트

- 타이핑 모드에 `힌트` 버튼을 추가했다.
- 힌트는 따라쓰기 고스트 글씨와 같은 방식으로 입력창 안에 흐리게 표시한다.
- 관사가 있는 정답은 관사가 힌트를 모두 소비하지 않도록 조정했다.
  - 1회: 관사 첫 글자
  - 2회: 단어 첫 글자
  - 3회: 단어 앞 두 글자
- 힌트 사용 시 난이도 평가에서 `쉬움/Easy`를 비활성화했다.
- 타이핑 입력창의 placeholder를 제거해 힌트 고스트와 겹치지 않게 했다.
- 힌트 버튼은 공유 이미지 생성 버튼과 같은 옅은 파랑 스타일로 맞췄고, `힌트/확인` 버튼 묶음 폭을 기존 정답 버튼 폭과 맞췄다.
